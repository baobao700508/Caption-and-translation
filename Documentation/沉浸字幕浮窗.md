# 沉浸字幕浮窗

字幕窗采用 C 版布局：正文占据完整高度，不保留常驻顶栏与底栏。默认尺寸为 820 × 180 pt，最小尺寸为 560 × 140 pt；已有窗口位置和尺寸继续使用保存值。

## 操作入口

右侧齿轮始终可见，打开现有的独立设置窗口。鼠标进入字幕窗时显示开始／结束方块和更多菜单；移出后只保留齿轮。右侧为操作保留空间，不覆盖字幕正文。左侧细状态标记显示运行或错误状态，完整状态可在控制面板查看。

更多菜单与空白处右键菜单提供字幕内容、菜单栏控制面板、设置、迷你条、课堂记录、回听、AI 追课、位置、鼠标穿透及隐藏入口。只有选择结束记录才停止会话；收起和隐藏继续记录。

“打开菜单栏控制面板…”使用原有 QuickControlsView，在屏幕内独立呈现，不依赖 Mac 菜单栏图标是否被刘海遮挡。设置、收起或展开字幕会关闭此面板；不会创建第二个音频采集或翻译会话。

所有记录按钮和字幕更多菜单的结束入口先弹确认框。取消继续记录；确认才调用原有停止流程。程序退出、错误处理、连接恢复和模式切换的内部收尾沿用原逻辑。

## 外观与正文

背景不透明度继续由现有设置中的“字幕与外观”调整，范围为 45%～100%，仅改变背景，文字不随之变淡。字号、模式、音源、SaT 设置和配置保存继续使用现有实现。

正文沿用 CaptionTranscriptView，包括临时文字更新、原译文关联、SaT 固定段落、滚动查看前文、回到最新和右键复制。原文采用较浅灰色与较小字号，译文使用白色；段落间保留留白，移除分隔线。

鼠标穿透仍提供独立的可点击恢复条；迷你条保留展开、记录与设置入口。浮窗允许接收键盘焦点，使原生确认框可操作，但不会因字幕更新主动抢焦点。

## 开发与验证

正式应用从合并后的主工程构建，桌面入口指向 `dist/LiveCaption.app`。独立验证使用 `LIVECAPTION_APP_PATH` 和单独的应用标识，避免改变正式应用偏好。模型下载、凭据配置和业务处理沿用主工程实现。

自动检查覆盖核心逻辑、原生控件、双语与长段落布局、窄窗及滚动追随。`--verify-interface` 和 `--interface-preview` 可用于界面预览，不采音或调用模型，不能替代实际语音验收。

真实课堂录音验收通过电脑声音采集，分别运行 Whisper 本机原文转写、新加坡 WebSocket 纯文字翻译和带译音同传。交互检查覆盖开始／结束确认及取消、独立设置、菜单栏控制面板、迷你条展开、原文／译文／双语切换、回看与回到最新、右键复制、AI 追课复制、隐藏后快捷键恢复、字号与背景透明度、鼠标穿透开关、后台整理开关自动保存、日志目录、译音回听和 SaT 离线检查。三条会话均记录正常收尾；纯文字线路只请求 text，带译音线路请求 text 与 audio，服务回显均为 server_vad。

这些检查验证界面整合和短录音业务连通性，不代表物理麦克风、所有输出设备、Google 在线线路或整节课延迟已重新验收。实际日志和录音保存在本机 `TestResults/immersive-merge/`，不进入公开仓库。
