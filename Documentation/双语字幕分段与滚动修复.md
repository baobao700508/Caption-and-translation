# 双语字幕分段与滚动修复

适用版本：LiveCaption 0.1.2。验证日期：2026-10-21。

## 使用效果

双语字幕按“原文第一段 → 对应译文第一段 → 原文第二段 → 对应译文第二段”的顺序显示，段落之间有分隔线。新文字默认跟随到最新位置；向上滚动查看前文会暂停跟随，点击“回到最新”恢复。

服务端有时会将四十多秒的连续讲话划为一个段落。长段默认显示两种语言的末尾预览，按窗口高度各保留一至三行，确保原文与译文同时可读；点击“展开本段全文”查看完整内容，并定位到该段开头。展开时暂停自动跟随。完整原文、译文和修订继续保留在课堂日志中，预览省略不会删掉正文。

## 原因与代码修改

原界面分别调用 `recentText(source)` 和 `recentText(translation)`，将多段英文汇总为一个文本块，再将多段中文放在其后。随着内容增长，自动滚动只能看到中文尾部，英文被推到窗口上方。原始日志已有供应商段落关联，但界面没有使用它。

| 修改 | 实现 | 解决的问题 |
| --- | --- | --- |
| 原译文逐段关联 | `Segment` 保留供应商原文 ID；`CaptionParagraph` 通过 `sourceProviderID` 在同一连接代次中配对 | 原文和对应译文紧邻显示；译文乱序到达也不会串段 |
| 最终事件保留关联 | `BailianProtocol` 的 `response.done` 同样附带原文关联及音频时间 | 没有中间增量、只有最终译文时也能配对 |
| 段落视图 | SwiftUI `LazyVStack` 逐段显示；长段按 AppKit 实测文字排版生成末尾预览，支持展开 | 两分钟后不再堆成上下两大块；单个长段也能同时看到两种语言 |
| 滚动控制 | `ScrollViewReader` 在内容布局完成后跟随；监听原生 `NSScrollView` 用户滚动通知 | 自动跟随新字幕，回看时不被拉走；展开定位到本段开头 |
| 完整日志与显示分离 | AppSession 从同一 Transcript 生成段落视图，预览裁剪只作用于显示 | 保留供 AI 读取的完整文字 |

未知关联的译文独立显示并标明“暂无对应原文”，不按到达顺序猜测配对。原文稍后到达时，已有明确关联的译文并入同一个段落。分段依据是供应商的段落关联，不宣称逐句或逐词对齐。

主要文件：`Sources/LiveCaptionCore/CaptionParagraph.swift`、`Transcript.swift`、`BailianConnection.swift`、`Sources/LiveCaptionApp/CaptionTranscriptView.swift`、`AppSession.swift`、`Views.swift`。

## 验证结果

| 检查 | 结果与证据 |
| --- | --- |
| 原故障重现 | 四分钟文字时间轴、12 组段落在旧版实际字幕视图中重放：末句中文可见，英文被挤出可读区域；`TestResults/caption-layout-before/result.json` |
| 发布版排版 | 同一回放的末段英文、中文同屏可见，12 组原译文逐段配对 |
| 单段超长与最小窗口 | 超长原译文可同时看到尾部；560×240 窗口保留两种语言，提供全文展开 |
| 显示模式 | 仅原文、仅译文、双语、纯转写及同声传译分别通过原生视图渲染检查 |
| 回看与跟随 | 手动滚动暂停跟随；新文字到来不拉走历史位置；恢复后可见最新双语 |
| 用户实际会话 | 本机重放 `2595b013-294b-4a6d-82a3-4c2d79a460ee` 的文字事件，已有原译段落全部配对 |
| 实际点击 | 点击展开后定位到该段开头；点击“回到最新”恢复双语预览；滚轮向上后出现回看状态与恢复按钮 |
| 数据回归 | 25 项检查通过，包含乱序配对、迟到原文、最终修订、连接代次隔离、最终译文关联，以及既有日志与音频检查 |
| 发布 | 0.1.2 构建与签名校验通过，桌面 LiveCaption 入口指向发布应用 |

发布版的 16 项字幕渲染与滚动检查全部通过：`TestResults/caption-layout-release/result.json`。代码与发布二进制证据：`TestResults/caption-layout-release/release-integrity.json`。本地复现命令为 `bash scripts/verify-caption-layout.sh`；可追加 `--caption-event-log /absolute/path/events.jsonl` 重放已有文字事件。

四分钟指测试文字事件覆盖的音频时间轴；回放采用加速注入，不代表重新运行了四分钟云端语音测试。以上检查验证字幕数据关联、排版和操作，不测量模型翻译准确率或语音传输延迟。
