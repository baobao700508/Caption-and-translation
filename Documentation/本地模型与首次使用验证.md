# 本地模型与首次使用验证

## 使用约定

普通用户从 App 设置中的“本地模型”按需准备 SaT 或 Whisper。未使用的模型不下载；SaT 下载操作包含独立 Python、固定版本依赖、ONNX 模型及分词器，Whisper 下载操作包含 Core ML 模型与分词器。模型不安装到 App 包、源码仓库或系统 Python。

首次创建配置默认选择本地 Whisper 原文转写、关闭 SaT 整理，不要求云端密钥。创建配置、打开设置、下载模型均不启动录音。已有配置不会被创建动作覆盖。需要云服务时，在“模式与音源”填写地区、工作空间与凭据；凭据成功存入钥匙串后，配置文件只保存非密钥字段，并保留其他设置。

SaT 模型文件按固定修订下载，校验长度与 SHA-256 后才替换正式文件。运行环境与模型通过实际离线推理后写入完成记录。Whisper 通过模型加载、分词器准备和短识别检查后写入必需文件清单；缺失或截断文件使可用检查失败。用户可取消、重试、检查并修复，以及查看安装日志。

## 已验证范围

| 检查 | 实际边界与结果 |
| --- | --- |
| 空目录 SaT 准备 | 下载独立 Python，安装固定依赖，下载并校验模型及分词器；完成离线分段推理 |
| 空目录 Whisper 准备 | 在独立模型目录下载 Turbo 与分词器，完成本机 GPU 加载及短识别检查 |
| App 下载按钮 | 原生设置中实际点击 SaT 和 Whisper 下载按钮，两者最终显示运行验证通过 |
| 取消与重试 | App 内取消正在安装依赖的 SaT 任务，然后重新下载成功；核心检查同时验证取消会终止子进程 |
| 文件损坏与网络中断 | 自动检查覆盖校验失败、不发布损坏文件、清理临时文件、保留已有文件和重新下载修复 |
| 已完成文件复用 | 相同哈希的模型文件不再次请求网络；Whisper 已有缓存通过准备入口复用并补齐验证记录 |
| 首次配置 | 原生界面实际点击创建配置，进入模型页；不加载真实云凭据、不自动录音、不覆盖已有配置 |
| 真实声音 | 新下载的 Whisper 对 25 秒 MIT 真人课堂音频完成原文转写及收尾；不代表物理麦克风采集验收 |
| 干净源码 | 仅从已提交源码归档开始，没有 Vendor、构建目录或项目虚拟环境，在只包含系统命令的 PATH 下执行 develop.sh，完成依赖准备、核心检查和 App 构建 |

可复现入口：

```bash
bash scripts/develop.sh
bash scripts/check.sh
python3 -m unittest discover -s Tests -p '*Tests.py'
bash scripts/setup-sat.sh sat-3l
swift run --scratch-path .build-selected-toolchain LiveCaptionModelSetup whisper
```

独立目录检查可在以上命令前设置 `LIVECAPTION_MODEL_HOME`。交互式首次使用检查可对构建包执行 `--verify-onboarding`，应同时指定隔离模型目录；该模式不读取云端钥匙串、不持久化用户界面偏好。

本机证据位于 `TestResults/model-onboarding/`：安装事件与日志、离线 worker 输出、Whisper 课堂识别结果、原生界面报告和干净源码构建日志。证据包含本机路径，模型与录音不随公开仓库上传。

## 验证边界

以上在 Apple Silicon、当前 macOS 与 Xcode 环境完成。隔离目录和干净源码验证不等于另一台全新 Mac 的硬件、账号与 Gatekeeper 验证。当前 App 为 ad-hoc 签名开发包，尚未完成 Developer ID 签名及公证；安装到新机器时的系统信任提示应单独处理。

本地模型准备不验证云端模型可用性、计费、翻译质量、长时间云连接稳定性或整场课堂延迟。既有音频采集、供应商协议、声音播放及 SaT 分段策略保留原有职责，下载成功不替代这些功能的独立验收。
