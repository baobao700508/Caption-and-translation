# Caption and translation

面向 macOS 的实时字幕、原文转写与同声传译项目。

## 仓库状态

本仓库已准备项目开发规范和 Git 基线，用于承接后续正式项目迁移。业务源码、依赖、应用包和测试资料尚未迁入，当前不提供可运行的应用。

## 迁移边界

本阶段仅建立新项目及公开远端仓库。现有 LiveCaption 项目继续在原位置开发；未经明确迁移指令，不复制或移动其业务文件，不修改原项目、配置、应用入口或运行状态。

后续迁移应以源项目当时的最新状态为准，保留必要的代码历史与验证证据，并核对第三方依赖及许可证。API Key、本机 MCP 配置、个人配置、课堂日志、录音和构建产物不随公开仓库发布。

## 初始化配置

项目使用统一 `project-init` 配置模板。`AGENTS.md` 和语言规范纳入版本管理；`.mcp.json`、`.codex/config.toml`、`.claude/settings.local.json` 仅保留在本机，由 `.gitignore` 排除。
