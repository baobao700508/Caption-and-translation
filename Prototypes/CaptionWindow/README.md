# 字幕浮窗原型

使用 SwiftUI 与 AppKit 实现的三个交互候选。它们是独立预览应用，不连接 AppSession，不采集声音，不调用识别、翻译或分段模型，不读写正式应用的配置与日志。

## 三个方向

| 方案 | 阅读与操作方式 | 取舍 |
| --- | --- | --- |
| A：单行顶栏 | 28 pt 顶栏保留状态、时长、开始／结束和更多；取消底栏 | 操作容易发现，仍保留一条顶栏 |
| B：侧边控制 | 上下全部交给字幕，32 pt 右侧栏保留两个操作和状态点 | 适合压低窗口高度，正文宽度减少 32 pt |
| C：沉浸阅读 | 无常驻工具栏；悬停时显示侧边操作，也支持右键菜单 | 阅读时最干净，操作需要主动呼出；侧边保留空间以免遮住正文 |

独立浮窗初始尺寸统一为 820 × 180 pt，最小为 560 × 140 pt。对照窗口中的三版共用内容、字号和演示状态，可直接比较空间分配。独立窗口可拖动、调整大小并保持浮在其他窗口上方。

## 构建与使用

需要 macOS 14.2 或以上及 Xcode 命令行工具，无第三方依赖。在此目录运行：

```bash
bash build.sh
open .build/CaptionWindowPrototypes.app
```

对照窗口提供课堂讲解、长句、未开始和连接恢复四种场景；支持原文／译文／双语、字号调整和逐字演示。每版的“独立试用”打开真实 NSPanel 浮窗，也可使用 ⌘1、⌘2、⌘3。

浮窗中的方块表示“结束记录”，不是暂停。点击方块、更多菜单或右键菜单中的“结束记录”都会先显示确认弹窗；选择“继续记录”保持运行，选择“结束记录”才停止更新并保留已有字幕。结束后显示三角形“开始记录”，再次开始无需确认。这些操作仅控制演示状态；“更多”与右键菜单可调整字幕、字号、只看最新段及复制示例译文。C 的控制默认隐藏，鼠标进入字幕区域时显示；对照页也可勾选“显示 C 的操作”。关闭独立预览可使用其“更多”菜单中的“关闭此预览”。

导出原生渲染预览：

```bash
.build/CaptionWindowPrototypes.app/Contents/MacOS/CaptionWindowPrototypes --render-only "$PWD/Outputs"
```

导出时使用实际挂载的 NSHostingView，包含原生菜单与滚动容器。`Outputs/` 包含三版对照、独立布局、C 操作展开、560 pt 窄窗长句、空状态和连接恢复截图；该目录与应用包均不纳入 Git。

## 复用与接入边界

沿用现有字幕窗的系统字体、灰色原文／白色译文、深色浮窗、青色状态、SF Symbols、右键菜单及 NSPanel 浮窗方式。三个候选共用 ReadingBody、CaptionIcon、CaptionMore 和 DemoSession，没有复制三套业务逻辑。

候选新增的部分仅负责工具栏布局与演示数据，保留在本目录。用户选定后，再把对应布局绑定到生产 AppSession；识别、翻译、分段、收尾和日志行为保持独立。正式接入时，设置、记录、回听和 AI 追课等原有低频入口可收纳至更多菜单或菜单栏；本原型不伪造这些业务功能已接入。

## 文件

- `CaptionProposals.swift`：三种布局、共用正文及可交互演示状态。
- `PreviewApp.swift`：对照窗口、独立浮窗、应用菜单与原生截图导出。
- `build.sh`：仅构建并签名此预览应用，不调用正式发布脚本。

当前阶段为三版候选预览，正式字幕窗未被替换。
